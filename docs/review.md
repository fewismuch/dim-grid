# 项目审查与修复记录

审查日期：2026-10-03。范围包括架构、目录结构、字段实现、视图处理、交互、类型约束、测试和生产构建。

## 总体判断

React + Ant Design + react-datasheet-grid 适合当前单页表格演示，无需引入后端或大型状态框架。原先最大的风险是记录没有稳定身份：把显示位置当作原数据位置，筛选、排序或分组后执行行操作可能覆盖其他记录或写入 undefined。自定义列还混淆了标量与完整记录的接口。

本次优先修复数据正确性，抽出独立领域层，保留现有 UI 组件分工，补齐验证和开发入口。

## 架构与结构调整

`src/model/table.ts` 集中管理不依赖框架的领域逻辑。`App.tsx` 编排界面和状态，`buildDsgCol.tsx` 负责表格库适配。`constants.tsx` 保留图标与展示常量，重新导出领域类型以兼容组件导入。

记录 ID 与字段 ID 均独立于显示名称和位置。创建与复制使用统一入口；分组内插入记录继承该组字段值。派生视图不直接取代原始数据，删除不可见记录不会被误触发。字段默认值、转换、空值定义和 JSON 解析共用实现。

自定义列在一个明确边界适配动态字段类型，其余行回调以完整记录为约束。使用实际列适配器的测试覆盖原先最危险的接口错误，而不只测试孤立的辅助函数。

## 尚存边界

1. 本地存储受浏览器容量、清理策略和同源限制影响，不提供云备份或多人同步。其他页面写入时暂停当前页保存，尚无并发合并协议。
2. 撤销历史仅在当前会话有效，最多 50 步；大表历史仍保留不可变数据快照，需根据实际设备评估内存。
3. 首屏主 JS 仍超过 500 KB，构建保留大 chunk 警告。后续若继续优化，应测量实际加载时间和交互延迟。
4. 内存多选／链接仍通过 JSON 字符串适配现有编辑器；保存层已有结构化格式，全面迁移仍需同步编辑器及剪贴板接口。
5. 暂无权限、多视图管理和协作。选项被删除后已有标签保留，避免隐式丢失，后续可增加批量映射入口。
6. 未做所有设备、浏览器和辅助技术组合的完整兼容性认证；分组测试是渲染规模验证，不是生产性能保证。依赖审计只表示本次数据库查询未检出已知漏洞。
